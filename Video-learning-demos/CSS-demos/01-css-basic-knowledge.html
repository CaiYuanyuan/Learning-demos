CSS 基础知识

css 基础知识：样式分类、选择器、属性、值、注释等。

1. 样式分类

css 样式分类：内联样式、内部样式、外部样式。

⑴ 内联样式：style 属性

内联样式：在 html 元素内部使用 style 属性，直接设置元素的样式。

例如：这是一个红色的文本，是当前标签 span 的 style 属性设置内联样式，我是没有设置内联样式的文本。

⑵ 设置内部样式：style 标签

设置内部样式：在 html 文档的 head 元素内部使用 style 元素，定义 css 样式。

例如：我是在 head 的 style 元素内部定义的样式。

⑶ 设置外部样式：link 标签

设置外部样式：在 html 文档的 head 元素内部使用 link 元素，引入外部的 css 文件。

例如：link 标签中设置 rel="stylesheet" href="css/basic.css"， 引入外部的 css 文件 basic.css。

在 basic.css 文件中定义的样式，会覆盖 head 元素内部定义 style 元素的样式。

2. CSS 选择器

2.1 基础选择器：单个选择器组成，根据元素的标签名、类名、id 、通配符来选择元素。

⑴ 元素选择器：标签名

元素选择器：根据元素的标签名来选择元素。

例如：p 标签选择器，会选择所有 p 标签。

⑵ 类选择器： .类名

类选择器：根据元素的类名来选择元素。

例如：.class-style 类选择器，会选择所有 class="为 class-style" 的元素。

⑶ id 选择器： #id

id 选择器：根据元素的 id 来选择元素。

例如：#id-style id 选择器，会选择 id="id-style" 的元素。

通配符选择器：选择所有元素。
