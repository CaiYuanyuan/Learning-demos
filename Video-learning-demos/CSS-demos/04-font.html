字体样式

1. 设置文字颜色： color 属性

文字颜色可以使用颜色值、颜色名称或十六进制颜色值。

⑴ 设置颜色为关键字颜色：我是关键字颜色，比如 颜色名称 red、green、blue 等。

⑵ 设置颜色为十六进制颜色值：我是十六进制颜色值，比如 #ff0000、#00ff00 等。

⑶ 设置颜色为 rgb 颜色值：我是 rgb 颜色值，比如 rgb(0, 255, 0)。

⑷ 设置颜色为 rgba 颜色值：我是 rgba 颜色值，比如 rgba(0, 0, 255, 0.5)。

2. 设置字体族： font-family 属性

字体族可以使用字体名称、字体族名称或字体族名称列表。

我是给这个段落单独设置的字体族，比如 "宋体"、"微软雅黑" 等。

实际开发中，一般会设置在 body 标签中，而且会是一个字体族名称列表。此处仅为测试。

3. 设置字体大小： font-size 属性

字体大小可以使用的单位：像素值 px、百分比值 %、em 值（相对父元素）、rem 值（相对根元素 html）等。

使用 font-size 属性给这个段落单独设置字体大小，比如 12px。

4. 设置字体风格、是否倾斜：font-style 属性

字体风格可以使用 normal（正常）或 italic（倾斜）。

我是给这个段落单独设置的字体风格，比如 italic，本来是不倾斜的，可以设置为倾斜。

我是 em 标签的内容，会自动倾斜。但通过 font-style: normal（正常）,可以设置为不倾斜。

字体粗细可以使用 normal、400（正常）或 bold、700（加粗）。

6. 设置文本装饰：text-decoration 属性

文本装饰可以使用 none（无装饰）、overline（上划线）、line-through（贯穿线/删除线）、underline（下划线）。

去掉下划线：我是超链接，原本是有下划线的，但是设置为 none 后，就没有下划线了。

我是给这个段落单独设置的文本装饰，比如 overline，本来是没有上划线的，可以设置为上划线。
