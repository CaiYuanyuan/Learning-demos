字体样式

设置文字颜色： color 属性

文字颜色可以使用颜色值、颜色名称或十六进制颜色值。

⑴ 设置颜色为关键字颜色：我是关键字颜色，比如 颜色名称 red、green、blue 等。

⑵ 设置颜色为十六进制颜色值：我是十六进制颜色值，比如 #ff0000、#00ff00 等。

⑶ 设置颜色为 rgb 颜色值：我是 rgb 颜色值，比如 rgb(0, 255, 0)。

⑷ 设置颜色为 rgba 颜色值：我是 rgba 颜色值，比如 rgba(0, 0, 255, 0.5)。

设置字体族： font-family 属性

字体族可以使用字体名称、字体族名称或字体族名称列表。

我是给这个段落单独设置的字体族，比如 "宋体"、"微软雅黑" 等。

实际开发中，一般会设置在 body 标签中，而且会是一个字体族名称列表。此处仅为测试。
