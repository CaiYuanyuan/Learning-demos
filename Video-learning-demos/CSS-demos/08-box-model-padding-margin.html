盒模型-内边距、外边距

1. 内边距 padding：设置元素的内边距，即元素内容与边框之间的距离

⑴ 内边距的取值方式：1~4个值，分别对应的内边距

未设置内边距：我是 div 标签的内容，没有设置内边距
设置一个值：padding: 10px; 所有方向（四条边）的内边距都相同
设置两个值：padding: 10px 20px; 1=上下内边距、2=左右内边距。
设置三个值：padding: 10px 20px 30px; 1=上边距、2=左右边距（相同）、3=下边距。
设置四个值：padding: 10px 20px 30px 40px; 顺时针： 1=上边距、2=右边距、3=下边距、4=左边距。

⑵ 单独指定某个方向的内边距：padding-方向词

padding-top、padding-bottom、padding-left、padding-right

设置左边距：padding-left: 10px; 左边方向的内边距为 10px

2. 外边距 margin：设置元素的外边距，边框外的空白，即元素与元素之间的距离

⑴ 外边距的取值方式：1~4个值，分别对应的外边距

未设置外边距：我是 div 标签的外容，没有设置外边距
设置一个值：margin: 10px; 所有方向（四条边）的外边距都相同
未设置外边距：我是 div 标签的外容，没有设置外边距
设置两个值：margin: 10px 20px; 1=上下外边距、2=左右外边距。
未设置外边距：我是 div 标签的外容，没有设置外边距
设置三个值：margin: 10px 20px 30px; 1=上边距、2=左右边距（相同）、3=下边距。
未设置外边距：我是 div 标签的外容，没有设置外边距
设置四个值：margin: 10px 20px 30px 40px; 顺时针： 1=上边距、2=右边距、3=下边距、4=左边距。
未设置外边距：我是 div 标签的外容，没有设置外边距

⑵ 单独指定某个方向的外边距：margin-方向词

margin-top、margin-bottom、margin-left、margin-right

设置左边距：margin-left: 50px; 左边方向的外边距为 50px

⑶ 行内元素：只有左右外边距有效（margin-left、margin-right），上下外边距、宽高都无效

行内元素：内边距、边框有效（多行文字时，上下内边距有效，但可能会导致重叠问题）

行内元素 span 1 行内元素 span 2

⑷ 块级元素、水平居中显示：块级盒子 本身有宽度≠父元素宽度、 左右外边距 auto，如 margin: 0 auto;

① 块级盒子本身必须有宽度（小于父元素宽度）：否则和父元素一样宽，看不出来是否居中显示。

② 块级盒子的左右外边距 设置为 auto：浏览器会均分左右外边距，即可水平居中显示。上下外边距不重要，可以不写，也不一定必须是 0 。块级元素水平居中，主要看左右外边距。

③ 常用的三种写法（确保左右外边距为 auto）：❶ margin: 0 auto; ❷ margin: auto; ❸ margin-left: auto; margin-right: auto;

我是需要水平居中的显示的块级盒子

④ 行内元素无法通过左右外边距 auto 实现水平居中显示（可以放在块级元素中，再设置左右外边距 auto 实现水平居中显示）

我是行内元素 span，我设置左右外边距 = auto也无法水平居中显示

⑸ margin 的 auto 属性值：浏览器自动计算，一般是占满一边的剩余空间

① 左外边距为 auto = 内容靠右，自动占满“左边剩余空间”； margin-left: auto;
② 右外边距为 auto = 内容靠左，自动占满“右边剩余空间”； margin-right: auto;
③ 左右外边距为 auto = 内容靠中间，自动占满“左右剩余空间”、两边均分剩余空间； margin-left: auto; / margin-right: 0 auto;

⑹ 外边距的合并（折叠）：并列的块级元素（兄弟）、上下外边距合并 = 较大那个的外边距

并列的块级元素、上下外边距合并，合并后的外边距 = 较大的那个外边距

⑺ 外边距塌陷：父子的块级元素，子元素设置上下外边距，会让父元素跟着塌陷移动

3 种解决方案（重要）：给“父元素”设置 ❶ 上边框（边框）、❷ 上内边距（内边距）、❸ 隐藏溢出 overflow: hidden

注：主要是父元素要有 上边框 border-top、上内边距 padding-top、隐藏溢出 overflow: hidden，才能防止塌陷。
