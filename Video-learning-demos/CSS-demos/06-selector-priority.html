CSS 选择器优先级

⑴ 优先级：!important > 内联样式（style）属性 > id 选择器 > 类、属性、伪类选择器 > 元素、伪元素选择器 > 通配符、继承

元素选择器设置的样式：我是 div 的标签内容，用来测试选择器的优先级，我没有其他属性。
类选择器设置的样式：我是 div 的标签内容，用来测试选择器的优先级，我有一个类 class="selector-class"。
id 选择器设置的样式：我是 div 的标签内容，用来测试选择器的优先级，我有一个类 class="selector-class" 和一个 id="selector-id"。
内联样式（style）属性设置的样式：我是 div 的标签内容，用来测试选择器的优先级，我有一个类 class="selector-class" 和一个 id="selector-id"，同时还有 style="color: purple;" 属性。
!important 属性设置的样式：我是 div 的标签内容，用来测试选择器的优先级，我有一个类 class="selector-class" 和一个 id="selector-id"，同时还有 style="color: purple;" 属性，但最终使用的是.important 中设置了 !important 的 样式。

⑵ 权重叠加

  • 我是 div 中的 ul 中的 li 中的 a 标签
  • 我是 div 中的 ul 中的 li 中的 a 标签
  • 我是 div 中的 ul 中的 li 中的 a 标签，但我的 li 带一个 class="special-li"

⑶ 继承权重是0：给父元素设置样式，被子元素继承后，只要子元素设置有样式，子元素的样式就会覆盖父元素的样式

我是 div 的标签内容，通过 .inherit-style 类设置的样式，字体颜色为蓝色。

我是 div 中的 p 标签，用来测试继承权重。父元素.inherit-style 类设置的样式，字体颜色为蓝色，但实际起效的是通配符 * 中设置的红色。当我单独设置 .inherit-style p 的颜色时，起效的是我自己设置的绿色。

⑷ 有默认样式的元素（h1~h6、a），会优先使用默认样式(标题的加粗、链接的下划线)，而不是使用继承来的样式。（但字体颜色可以从父元素继承）

需要修改标题的加粗、链接的下划线，需要给“子元素本身”设置 font-weight 或 text-decoration 属性，而不是通过继承。

我是 header 中的 h1 标签

我的颜色是通配符改变的，在父元素 header 中设置的 font-weight，在 h1 标签中不会生效，因为 h1~h6 标签会优先使用自己的默认样式，而不是继承来的样式。如果要改变 h1 标签的 font-weight，需要在 h1 标签中设置 font-weight 属性。

我是 header 中的 a 标签，我有默认下划线，父元素中设置取消下划线，对我不起作用，因为我有默认下划线。在我自己的 a 标签中设置 text-decoration: none; 才能取消下划线。
