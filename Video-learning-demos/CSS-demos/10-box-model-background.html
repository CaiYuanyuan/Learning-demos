① 背景色 background-color：只能设置纯色

背景颜色：我设置了盒子的背景颜色为淡蓝色 background-color: lightblue;

② 背景颜色 + 透明边框：背景色范围 = 到“边框区内”

背景颜色 + 透明边框：我设置了盒子的背景颜色为淡蓝色 background-color: lightblue;

透明边框，透明度为0.1 ，border: 10px dashed rgba(0, 0, 0, 0.1);能看出来背景色从边框下面透出来，如果设置为 0，则边框完全就是背景色。
