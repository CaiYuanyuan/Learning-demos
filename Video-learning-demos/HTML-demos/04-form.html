表单标签

表单标签 form：用于收集用户信息，例如用户名、密码、姓名等，是表单控件的容器。

1. 输入标签 input：收集用户输入信息，单行文本框、密码、上传文件、单选按钮、复选框、日期、时间、数字等

⑴ 输入类型 type 属性：根据 input 的 type 属性决定

单行文本框：type="text"

密码：type="password"

上传文件：type="file"

单选按钮：type="radio"

复选框：type="checkbox"

日期：type="date"

时间：type="time"

数字：type="number"

提交按钮：type="submit"

重置按钮：type="reset"

⑵ placeholder 属性：提示信息（placeholder）属性：提示用户应该输入什么内容

⑶ name 属性：控件的名称，区分控件。用于标识表单控件，提交表单时会将该属性值作为参数名发送到服务器端，后端处理时，根据对应的名字找到对应的表单控件。

⑷ maxlength 、minlength 属性：最大输入长度、最小输入长度。用于限制用户输入的字符数量。

⑸ accesskey 属性：访问的快捷键。用于快速定位到该控件。windows 下按 alt + 快捷键即可定位到该控件。比如 B 站，alt +s 可以定位到搜索框。

⑹ autocomplete 属性：自动完成填写。用于自动填写表单控件的值。默认值为 on，自动填写。根据用户的历史输入值自动填写。关闭自动填写 off。对于隐私敏感信息，建议关闭自动填写。

  • 单选按钮实现单选：相同的 name 值。name 相同，分为一组，则单选按钮只能选择一个选项，实现单选。

    要将单选按钮的值提交给服务器端：需要设置 name 属性、value 属性，形成“名称/值对”。才能把选中项的名称和值提交给服务器端。

    默认选中项：设置 checked 属性，布尔属性。

    性别：

  • 复选框 checkbox：设置相同的 name 值，分为一组，但可以多选。被选中项的名称/值（name、value值）会提交给服务器端。

    爱好：

  • 上传文件 type="file"：上传用户文件，例如图片、视频等。必须有 name 属性，才能上传成功。特殊：value 属性不需要设置，为只读。部分方法下，也可省略 name 属性。

    上传文件的类型 accept 属性：初步指定上传文件的类型，多个类型用逗号隔开。例如：image/* 上传图片文件，video/* 上传视频文件，或者使用文件的扩展名，例如：.jpg、.png、.mp4 等。

    上传多个文件 multiple 属性：布尔属性。直接滑动选多个或按住 ctrl 选多个文件。

    实际开发中隐藏上传按钮：设置 style="display: none;" 隐藏上传按钮。然后设置自定义的漂亮的外观按钮，再用 js 实现点击按钮触发上传文件。

2. 多行文本域 textarea：收集用户输入的多行文本，例如评论、描述等；

textarea：只能输入可换行的多行纯文本，常用于用户的评论、反馈等，需要输入大量纯文字的场景。如果要添加表情，图片等其他内容，需要使用 div 标签实现自定义的内容区。

多行文本域名称 name 属性：提交值时必须属性。

可见行数和列数 rows、cols 属性：文本域的可见行数、列数。默认值为 2 行，20 列。

提示信息 placeholder 属性：提示用户应该输入什么内容。

3. 下拉列表 select：收集用户选择的选项，例如城市、国家等；

下拉列表的选项（option 标签）：用户可以从下拉列表中选择一个选项。

下拉列表的默认选中项（selected 属性）：设置 selected 属性，布尔属性。单选按钮和复选框的默认选中项，需要设置 checked 属性。注意区分。

必须搭配的属性：select 的 name、option 的 value，才能把选中项的名称和值提交给服务器端，select.="option.value"。

4. 按钮 button 标签:定义一个按钮，元素内容可以放文本、图像等

按钮显示内容 = 标签内容

disable 属性：禁用按钮，用户不能点击。

5. 标签 label：表单元素的说明，点击标签内容，可以聚焦到对应的表单元素上，扩大可点击范围，提高可访问性

关联方式1：属性关联。label 标签的 for 属性，关联表单元素的 id 属性。

例：label.for = "input.id"

关联方式2：直接包裹在 label 内部。直接用 label 标签包裹表单元素或文本。

例：label>input
